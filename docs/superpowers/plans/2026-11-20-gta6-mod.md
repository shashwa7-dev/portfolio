# GTA 6 Mod and Vice Hunt Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A temporary, flag-gated GTA 6 mode for the hero (spin or footer palm turns it on, with the owner's track) plus a self-contained hunting game in `games/vice-hunt/`, started from a pistol in the hero.

**Architecture:** A tiny external store toggles `data-mod="gta6"` on `<html>`. Everything heavy (backdrop, colour overrides, music, game host) lives in one lazily imported client component mounted in the hero. The game is a zero-dependency TypeScript package reached only through `import("@games/vice-hunt")`.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript, Tailwind 4, vitest, canvas 2D, Web Audio, YouTube IFrame API.

**Spec:** `docs/superpowers/specs/2026-11-20-gta6-mod-design.md` (read it first; it is the source of truth for values).

## Global Constraints

- Branch `gta6-mod`. Commit after each task. Do not push.
- Read `CLAUDE.md` before coding. Its rules apply: no em-dashes in user-facing copy; no `text-[Npx]`; Phosphor icons only from `@phosphor-icons/react/ssr`; no `transition-all`; motion durations come from tokens (`--duration-*` in `app/globals.css`); comments explain why, matching the codebase's comment style.
- This is Next.js 16: read `node_modules/next/dist/docs/` for any API you use (`next/dynamic`, etc.).
- Flags in `lib/gta6.ts`: `export const GTA6_ENABLED = true;` and `export const VICE_HUNT_ENABLED = true;`.
- Track id `aonTwBM1AZM` must only appear in files reached by dynamic import (never in a file a server component imports statically).
- Wallpapers already exist: `public/gta6/wallpapers/01.webp` to `07.webp`. Art already exists: `games/vice-hunt/src/art/sprites.ts`, `games/vice-hunt/src/art/gun.ts`. Do not redraw.
- Silence: never play audio in automated runs. Under `navigator.webdriver`, the game's sound module is a no-op and the YouTube player is never created. Headless Chrome checks always use `--mute-audio`.
- Colours (HSL triplets, the token format in `globals.css`): light `--accent: 337 52% 55%`, `--accent-hover: 337 47% 47%`, `--accent-foreground: 0 0% 100%`, `--ring: 337 52% 55%`; dark `--accent: 357 80% 79%`, `--accent-hover: 356 80% 84%`, `--accent-foreground: 251 26% 12%`, `--ring: 357 80% 79%`. Aqua "live" ink: light `184 53% 38%`, dark `175 51% 67%`.
- Game stats (from the spec table): rabbit speed 0.55 to 0.75 hero widths/s, hits 1 or 2; iguana 0.25 to 0.6, hits 3, pauses 0.2 to 0.8 s; flamingo 0.2 to 0.3, hits 2 or 3; bigfoot 0.08 to 0.12, hits 7 or 8, 6% spawn chance once 8 s have passed, at most one alive. Spawn every 0.9 to 1.6 s, at most 6 alive, at most 12 bullet holes.

## Review Focus

1. **Narrow screens:** on a 390px phone, the hero text spans the full width, so a left-to-right veil leaves text over bright art. Below `md` the veil is a flat 82% (Task 5 checks this in a 390px screenshot).
2. **Activating twice / toggling fast:** palm clicked during the fade-out, or the fifth star landing while the mode is already on, must not create a second player or a second backdrop (Task 5 test: the store's `set(true)` when already on notifies nobody; the mount keys on the store).
3. **Exit during the game:** Exit, the palm or the track ending while the game runs must tear down cleanly: scroll unlocked, cursor back, holes cleared, no orphan listeners (Task 6's scripted teardown check).
4. **Resizing during the game:** a window resize must resize the canvas and the world without stretching sprites or losing hit accuracy (Task 3 test `resize keeps animals on their lanes`).
5. **Background tab:** the game loop and the slideshow must not run while the tab is hidden, and returning must not apply a huge `dt` (Task 3 test `step clamps dt to 0.05`).

### Task 4: Vice Hunt rendering, gun, sound and public API

**Files:**
- Create: `games/vice-hunt/src/sprites.ts` (decodes art to images), `games/vice-hunt/src/render.ts`, `games/vice-hunt/src/gun.ts`, `games/vice-hunt/src/cracks.ts`, `games/vice-hunt/src/cracks.test.ts`, `games/vice-hunt/src/sound.ts`, `games/vice-hunt/src/index.ts`

**Interfaces:**
- Consumes: Task 3's `World` API, `art/sprites.ts` (`SPRITES`), `art/gun.ts` (`GUN_SVG`, `GUN_VIEWBOX`).
- Produces (`index.ts`): `startHunt(host: HTMLElement, options?: HuntOptions): Hunt`, `preloadHunt(): Promise<void>`, and the types `Kind`, `Kills`, `HuntOptions = { onKills?(kills: Kills): void; onShot?(x: number, y: number, hit: Kind | null): void; onExit?(): void; muted?: boolean }`, `Hunt = { destroy(): void }`. Coordinates passed to `onShot` are CSS px relative to `host`.
- Produces (`cracks.ts`): `crackPath(cx: number, cy: number, rng: Rng): string` (an SVG path `d`: 7 to 11 jagged spokes of 28 to 74px plus partial rings at 35% and 65%, as in the approved prototype).

Behaviour:
- `preloadHunt()` decodes every sprite frame and the gun into `HTMLImageElement`s (via `Blob` + object URL or `data:` URL, then `img.decode()`), caches them module-wide, and resolves once; later calls return the same promise.
- `startHunt` appends one layer to `host` (absolute, inset 0, `cursor: none`, `touch-action: none`, z above the host's content): a DPR-aware canvas for animals, poofs and holes; the gun (`GUN_SVG` in a positioned element, 210px wide, bottom of the layer, sliding under the aim point and leaning toward it, recoil on fire: `translateY(22px) scale(1.12) rotateX(14deg)` and back over 190 ms, a muzzle flash for 80 ms at the front sight); a crosshair (white cross with a red centre dot) at the pointer; a score strip bottom-left (one 20px sprite icon and count per kind, in order rabbit, iguana, flamingo, bigfoot, plain sans text). Pointer hidden over the layer only.
- One rAF loop; pauses while `document.hidden`. Mirrors sprites for leftward runs. Two-frame cycle: 0.18 s per frame (bigfoot 0.3 s). Flash = draw white silhouette (`globalCompositeOperation = "source-atop"` on an offscreen copy). Bigfoot draws a health bar above its head. Kill: a poof of 10 particles over 0.4 s (pink feathers for flamingo, dust for the others).
- Click (primary button) inside the layer: `shoot`, draw a hole at the point (dark centre, light rim, `crackPath` in white over a faint dark offset), keep at most `MAX_HOLES` (oldest dropped), play the shot sound, call `onShot`, call `onKills` when kills change, give the layer a 120 ms shake.
- `Escape` keydown on `window`, or right-click on the layer (prevent the menu): call `onExit`. The host then calls `destroy`.
- `destroy()` cancels the loop, removes the layer and every listener, and is safe to call twice.
- `sound.ts`: `createSound(muted: boolean): { shot(): void; hit(): void; kill(): void; close(): void }`. Muted when `muted` or `navigator.webdriver`. Lazily creates one `AudioContext` on the first call. Shot: 120 ms noise burst through a lowpass sweeping 4000 to 600 Hz plus a 60 Hz sine thump decaying over 150 ms, peak gain 0.35. Hit: short 900 Hz blip, gain 0.12. Kill: two-note down chirp, gain 0.15.
